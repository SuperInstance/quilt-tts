# quilt-tts

**What this repo is**: a substrate that turns canon lores into speech.

Substrate transition in 24 lines.

- canon lore → ElevenLabs API → MP3 file
- the canon gets *spoken* through the substrate walker
- the word becomes voice, the voice becomes record, the record becomes canon

The Quilt substrate walker canon was always meant to be heard.
This is the gate that lets it speak.
